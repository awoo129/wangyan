# 儿童脓毒症免疫瘫痪研究 - 机器学习综合分析报告

## 任务完成总结

本研究完成了以下两个主要任务：

---

## 任务1: 机器学习筛选最优标志物组合

### 使用的特征选择方法

1. **LASSO回归** (L1正则化)
   - 筛选出非零系数的基因
   - 减少特征维度，防止过拟合

2. **随机森林** (200棵树)
   - 基于特征重要性排序
   - 捕获非线性关系

3. **共识方法**
   - 综合LASSO和随机森林的排名
   - 提高特征选择的稳定性

### 核心标志物（5个MHC相关基因）

| 排名 | 基因 | 功能描述 |
|------|------|----------|
| 1 | **CIITA** | MHC class II转录激活因子 |
| 2 | **CD74** | MHC class II不变链 |
| 3 | **HLA-DQA1** | MHC class II α链 |
| 4 | **HLA-DRA** | MHC class II α链（已验证标志物） |
| 5 | **HLA-DQB1** | MHC class II β链 |

### 模型性能

| 数据集 | 准确率 | 敏感性 | 特异性 | AUC |
|--------|--------|--------|--------|-----|
| 训练集(GSE26378) | 0.8544 | 0.9268 | 0.5714 | 0.9187 |
| 验证集(GSE26440) | 0.7923 | 1.0000 | 0.1562 | 0.9675 |

**关键发现**: 验证集AUC达到0.9675，表明模型具有良好的泛化能力。

## 任务2: 构建IPS（免疫瘫痪评分）

### IPS评分公式

```
IPS = Σ(wi × expr_i)  (标准化后)
```

### 基因权重

| 基因 | Logistic权重 | LASSO系数 | RF重要性 |
|------|-------------|-----------|----------|
| CIITA | -0.498 | 1.481 | 0.244 |
| CD74 | +0.149 | 1.038 | 0.233 |
| HLA-DQA1 | -0.905 | 0.755 | 0.187 |
| HLA-DRA | +1.423 | 0.471 | 0.185 |
| HLA-DQB1 | -1.024 | 0.000 | 0.150 |

### 阈值确定（Youden指数）

- **最佳阈值**: 0.3636
- **敏感性**: 96.94%
- **特异性**: 84.38%

### 临床解释

- **IPS > 0.3636**: 提示免疫瘫痪状态（高风险）
- **IPS ≤ 0.3636**: 提示免疫功能正常（低风险）

### IPS分布统计

| 数据集 | 组别 | 均值 | 标准差 |
|--------|------|------|--------|
| 训练集 | 正常 | 0.197 | 0.134 |
| 训练集 | 脓毒症 | 0.536 | 0.197 |
| 验证集 | 正常 | 0.278 | 0.089 |
| 验证集 | 脓毒症 | 0.550 | 0.151 |

## 生物学意义

### HLA-DRA的核心作用
- HLA-DRA是MHC class II的主要组成基因
- 编码T细胞呈递抗原的受体
- 在脓毒症免疫瘫痪中显著下调

### 免疫调控机制
```
脓毒症 → 免疫激活 → 免疫抑制 → 免疫瘫痪
                              ↓
                      MHC II下调
                      CIITA下调
                      抗原呈递障碍
                              ↓
                      T细胞功能受损
```
