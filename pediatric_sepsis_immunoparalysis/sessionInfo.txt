=================== Analysis Pipeline ===================

1. Data acquisition: GEO (GSE26378, GSE26440, GSE63042, GSE65682)
2. Preprocessing: RMA normalization (oligo), log2 transformation
3. Batch correction: ComBat (sva package)
4. Differential expression: limma (microarray), DESeq2/edgeR (RNA-Seq)
5. Feature selection: LASSO logistic regression (glmnet)
6. IPS scoring: Weighted linear combination of 5 MHC II genes
7. Model evaluation: ROC/AUC (pROC), bootstrap validation
8. External validation: GAinS cohort (ArrayExpress E-MTAB-4451)
9. Visualization: ggplot2, pheatmap, plotly
