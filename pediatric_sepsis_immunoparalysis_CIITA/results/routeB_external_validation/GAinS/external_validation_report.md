# GAinS数据集 - 成人IPS外部验证报告

## 研究概述

**数据集**: GAinS (Genomic Approaches in Sepsis)  
**来源**: E-MTAB-4451 (ArrayExpress)  
**平台**: Illumina HumanHT-12 V4.0  
**样本数**: 106例成人脓毒症（社区获得性肺炎诱发）

## 方法

### 路线B成人IPS公式
```
IPS = -1.7212
    + 0.9768 × HLA-DMB
    - 0.9639 × HLA-DMA
    + 0.7495 × CIITA
    - 0.6438 × CD74
    + 0.5596 × HLA-DPB1
    - 0.5171 × HLA-DQB1
    - 0.4880 × HLA-DRB1
    + 0.1911 × HLA-DRA
    + 0.1516 × HLA-DQA1
```

**阈值**: 0.3167 (IPS ≥ 0.3167 定义为IPS高)

## 发现与讨论

### 主要发现

1. **平台效应显著**: 在GAinS数据集中，所有IPS评分均低于原始阈值(0.3167)，导致灵敏度为0。这表明原始IPS公式在Illumina平台上的直接应用存在局限性。

2. **AUC低于内部验证**: GAinS验证AUC为0.5495，低于GSE65682的0.696。这可能由于:
   - 探针替代：HLA-DMA使用替代探针(ILMN_1678255)
   - 平台差异：Affymetrix vs Illumina
   - 队列差异：社区获得性肺炎 vs 混合脓毒症

3. **SRS分型关联不显著**: Mann-Whitney p = 0.4037，表明IPS在区分SRS1和SRS2方面无显著统计差异。

4. **28天死亡率无关联**: IPS与28天死亡率之间未发现显著关联(p = 0.7163)。

### 局限性

1. HLA-DMA探针为替代探针，可能影响评分准确性
2. 跨平台验证需要平台特异性校准
3. 样本量相对较小(n=106)

### 建议

1. 对Illumina平台数据进行重新校准
2. 考虑开发平台特异性的IPS公式
3. 需要更大的外部验证队列
